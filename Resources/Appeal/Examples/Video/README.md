# Video examples

`Play_Video` displays the included Sample.mp4 as a cut scene. `Video_On_Surface` applies its frames to a UV-mapped 3D screen. Both use the standard configured modules, call Video Update once per frame, and close the clip before Graphics cleanup. Replace Sample.mp4 with a file under Resources/Video/Movies or load an absolute/direct media URL.

The sample includes a tone. Control sound with Audio Set_Volume_Percent and Audio Mute / UnMute. Pause/Stop/Seek belong to Video so its image and soundtrack move together.
