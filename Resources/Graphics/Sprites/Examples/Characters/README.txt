Adam_Movement.png and Eve_Movement.png are unchanged movement sheets extracted
from Adam_V1.zip and Eve_V1.zip in this directory. Each cell is 64x64 pixels,
with eight columns and five rows. Standing uses indices 0-7; Walking uses 8-15.
The archives contain the original metadata and CC0 licenses.
The example uses these sheets directly; individual frame PNGs are not required.
