Coding Format

Red Whistle Productions uses an open-brace-on-new-line style for Appeal scripts and for C/C++ source. This is the official format for the project because it makes missing braces and scope boundaries easier to see.

Appeal Script Blocks

Place { on its own line. Place } on its own line. Tab-indent everything inside the block.

Loop While Var Main_Open == 1
{
	Graphics Update
	Input Update Default

	If Var Game_State == Menu
	{
		Graphics GUI_Begin Main_Menu
		Graphics GUI_Button Start_Button Start Start_Game
		Graphics GUI_Button Quit_Button Quit Quit_Game
		Graphics GUI_End
	}
}

C and C++ Blocks

Use the same brace style in native code. Keep edits scoped to the function or module being changed unless a broader reformat is specifically requested.

if(Window == nullptr)
{
	return;
}

for(auto &Item : Windows)
{
	Render_Window(Item.second);
}

Script Organization

  • Main.Appeal is the default startup script.
  • Setup/Config.Appeal loads modules and default plugins.
  • Setup/ scripts configure reusable systems such as graphics and audio.
  • GUI/ scripts define reusable GUI panels.
  • Test/ scripts test modules, plugins, demos, and language features.
  • Default module configuration scripts should use Default_<Module>_Config.Appeal when added.

Command Style

Module commands use the module name first. This mirrors the original namespace idea for static modules and keeps the script explicit.

Graphics Render
Audio Update
Input Set_Key_Down Key_Escape Graphics.Close_All

Debug Style

Debug is off by default. Enable it only in scripts that are testing behavior or diagnosing a problem.

Appeal Debug On
Graphics Debug True
Audio Debug 1

Graphics Debug Off
Audio Debug False
