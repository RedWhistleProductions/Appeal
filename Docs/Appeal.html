Appeal Runtime

Appeal is designed as a general-purpose programming language built around command streams. A command stream can come from a local file today and can later come from a network data source, generated script, package system, editor, replay, or other provider.

Design Direction

Appeal itself is not the game engine. Bananas is the game-focused distribution built on Appeal, similar to how Anaconda is a Python distribution. The same Appeal language and module API should also be usable later for tools and a browser that replaces HTML and JavaScript with Appeal scripts and trusted native plugins.

The runtime and module APIs are intended to stay platform independent. Plugins are compiled for each platform, so the same Appeal script can run with different optimized backends and assets.

Runtime Paths

Path Purpose
./Resources Default resource root.
./Resources/Appeal Default folder for Appeal scripts.
./Resources/Appeal/Setup Reusable setup scripts, including Config.Appeal and module setup scripts.
./Resources/Appeal/GUI Reusable GUI scripts for settings panels and future tools.
./Resources/Appeal/Test Test scripts for language features, modules, plugins, and demos.
./Resources/Modules Default folder for built dynamic modules and their plugins.
./Resources/<Module> Default resource folder for a module, such as Resources/Audio or Resources/Graphics.

Startup Flow

The executable starts by running Main.Appeal unless a startup script is provided as an argument. Main.Appeal normally runs Setup/Config.Appeal, which loads the default modules and plugins.

Run Setup/Config
Done

Starting with a named script is useful for tests, tools, and launching directly into a game.

Appeal.exe Media_Player
Appeal.exe Test/Test_Graphics

Core Commands

Command Arguments Behavior
Run script Loads and switches to another script from Resources/Appeal.
Return none Returns from the current data source to the previous one.
Done none Stops the current run loop and closes the app.
Print text Writes text to the terminal.
Debug On, True, 1, Off, False, or 0 Turns core debug output on or off.
Add_Dynamic_Module module plugin Loads a module binary, registers its interpreter, and initializes the named plugin.
Delay seconds Pauses execution for an integer number of seconds.
Set_Var name value Stores a variable in the data manager.
Del_Var name Removes a variable from the data manager.
If left operator right { ... } Runs a block when the comparison is true.
Loop count { ... } Runs a temporary loop function body multiple times.

Modules And Plugins

Appeal modules are platform-independent command dictionaries. Plugins are platform-specific implementations loaded by those modules. Appeal scripts call module commands; the module parses arguments and forwards work to the plugin.

Add_Dynamic_Module Audio Appeal_SDL2_Audio
Audio Load_Play_List PlayAll.txt
Audio Play_Song "Folk Song"

Functions And Callbacks

Appeal scripts can define functions and attach them to GUI controls or input events. A callback target can be an Appeal function name or a module function written as Module.Function. Use None when no callback should be attached.

Graphics GUI_Button Play Play Audio.Play
Graphics GUI_Slider_Int Volume Volume Var Volume 0 100 Audio.Set_Volume_Percent
Graphics GUI_Checkbox Auto_Play Auto_Play Var Auto_Playing Audio.Set_Auto_Play
Graphics GUI_Button Camera_Reset "Reset Camera" Reset_Camera_Function
Graphics GUI_Slider_Float Perspective_FOV "Field Of View" 45.0 10.0 120.0 None

Digital callbacks call a function with no arguments. Value-changing controls use analog callbacks; module callbacks receive an integer value, and Appeal callbacks can read the current callback value through the runtime.

Safety Direction

Appeal script variables are strings so plugins can cast and validate data at the API boundary. Plugins should check type, range, and permissions before acting. Depending on the command, invalid values may be clamped, rejected, counted toward shutdown, or treated as fatal.

Remote scripts should not be able to install, replace, or update native plugins. Plugin updates belong to trusted repositories and user-approved package operations.
