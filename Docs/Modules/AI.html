AI Module

The AI module manages NPC brains and behavior through swappable plugins. It is intended to let games choose simple, lightweight AI on limited systems and richer AI on stronger systems without changing the Appeal script API.

Loading

Add_Dynamic_Module AI Test_AI
Run Test/Test_AI

Plugin Load Plan

Like Mechanics and Physics, AI stores named plugin slots with file names, loaded plugin pointers, and wanted flags. Scripts can load all AI backends, only the current scene's backends, or one backend at a time.
