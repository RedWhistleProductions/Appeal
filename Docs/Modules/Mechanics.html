Mechanics Module

The Mechanics module controls gameplay movement and interaction rules. It is designed to hot-swap mechanic plugins as the player changes context, such as walking, swimming, driving, flying, or using a menu.

Plugin Load Plan

The module stores plugin slots by name. Each slot has a plugin file name, an optional loaded plugin pointer, and a wanted flag. This allows the script or setup layer to keep all plugins loaded on strong systems, load only scene plugins on medium systems, or load one at a time on limited systems.
