Graphics Module

The Graphics module is the visual system for Appeal and Bananas. It covers windows, cameras, 2D and 3D resources, text, Dear ImGui GUI commands, rendering, and frame updates through a stable Appeal-facing API.

SDL2 Backend

Appeal_SDL2_Graphics uses SDL2 for windows, OpenGL for rendering, Dear ImGui for GUI commands, SDL2_ttf for text, SDL2_image for image loading, and Assimp for model loading when the built library is available.

GUI support remains part of the Graphics module and plugin for now. This keeps windowing, rendering, input event processing for ImGui, and GUI drawing in one backend.

GUI Callback Convention

Interactive GUI controls now take a final function argument. The target can be an Appeal function, a module function such as Audio.Play, or None.

Graphics GUI_Button Play Play Audio.Play
Graphics GUI_Small_Button Reset Reset_Camera None
Graphics GUI_Slider_Int Volume Volume Var Volume 0 100 Audio.Set_Volume_Percent
Graphics GUI_Slider_Float Perspective_FOV "Field Of View" 45.0 10.0 120.0 None
Graphics GUI_Drag_Float Camera_X "Camera X" 0.0 -100.0 100.0 0.1 Update_Camera_X
Graphics GUI_Input_Text Player_Name "Player Name" Billy None
Graphics GUI_Checkbox Loop_Current Loop Var Looping Audio.Set_Current_Loop
Graphics GUI_Menu_Item Open_Settings Settings Open_Settings_Menu

Buttons and menu items call digital functions with no arguments. Sliders, drags, numeric inputs, text inputs, checkboxes, selections, and radio buttons call value-changing callbacks. Float controls currently send scaled integer values to module callbacks.

Reusable Scripts

Resources/Appeal/Setup/Graphics_Setup.Appeal sets up basic graphics state. Resources/Appeal/GUI/Graphics_GUI.Appeal builds a reusable Graphics settings window with controls for window position, viewport, perspective, and camera settings.
