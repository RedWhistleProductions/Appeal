Package Module

The Package module is the repository and package-management scaffold for modules, plugins, assets, and compressed packages.

Loading

Add_Dynamic_Module Package Appeal_Standard_Package
Run Test/Test_Package_Standard

Packages are expected to come from dedicated repositories, similar to how Linux distributions manage apps. Different devices or distro maintainers can provide repositories with plugins and assets tuned for that platform.

Plugin Dependency Manifests

A future plugin manifest should list third-party dependencies, platform packages, build requirements, runtime requirements, license information, and install scripts. The package system can then install dependencies when a trusted plugin is installed. Remote Appeal scripts should not be able to change native plugins.
