Network Module

The Network module is the command-stream, transfer, and multiplayer network scaffold. It is designed to let Appeal read commands from a server and run them like a script, download assets, and later update modules and plugins through trusted package flows.

The Network module can play client and server roles at the same time. For example, a LAN host can listen for other players while also acting as a local player client.

Loading

Add_Dynamic_Module Network Appeal_SDL2_Network
Run Test/Test_Network_SDL2

The current network direction starts with a simple unencrypted debug-friendly connection model. The later security direction is key-based authentication and encryption, similar in spirit to SSH but not necessarily a literal SSH connection.
