Physics Module

The Physics module wraps physics simulation through swappable plugins. It can use different backends or different simulation complexity depending on the device, scene, and active mechanics.

Loading

Add_Dynamic_Module Physics Test_Physics
Run Test/Test_Physics

Default Backend Direction

The current default non-test backend is intended to use Box2D for lightweight 2D physics. Future plugins can provide other engines for 3D or specialized simulations while keeping the same Appeal-facing API.
