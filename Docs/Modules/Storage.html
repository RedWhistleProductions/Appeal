Storage Module

The Storage module is the persistent data scaffold for settings, save data, and database-backed key/value data. The default direction is SQLite because it is small, local, portable, open source, and easy to copy or back up.

Loading

Add_Dynamic_Module Storage Appeal_SQLite_Storage
Run Test/Test_Storage_SQLite

The API should stay database-neutral so a later PostgreSQL, MongoDB, or other storage plugin can use the same Appeal commands where possible.
