Appeal Language Reference

Appeal docs

Run Appeal.exe path/to/Script.Appeal. With no argument, Appeal runs Main.Appeal from its resources. Names are case sensitive. Quote text containing spaces. Prefix module commands with the module name.

Basic functions

SyntaxBehavior
DoneStop execution.
Print ValuePrint a value.
Run ScriptRun a script; Run Var Name reads its path from a variable.
Define_Function Name ... End_FunctionDefine a function.
Call NameRun a defined function.
ReturnEnd the current source.
Return_Value ValuePublish an expression result without ending the function.
Set_Var Name ValueStore a variable.
Del_Var NameRemove a variable.
Read_Line Variable StatusRead console input; Status is 1 on success, 0 on EOF.
Print_Global NamePrint a module global.
Set_Var_Global Variable GlobalCopy a global into a variable.
Delay SecondsPause for integer seconds.
If Left Operator Right { ... }Execute a conditional block.
Loop While Left Operator Right { ... }Repeat while true; a script path can replace the block.
Loop Until Left Operator Right { ... }Run at least once, stopping when true; a script path can replace the block.
Add Left RightReturn a sum.
Subtract Left RightReturn a difference.
Multiply Left RightReturn a product.
Divide Left RightReturn a quotient; rejects division by zero.

Advanced functions

SyntaxBehavior
Debug ValueToggle diagnostics.
Add_Dynamic_Module Name PluginLoad a module and plugin.
Add_Extension NameLoad an extension.
Add_Dynamic_Extension NameAlias of Add_Extension.
Add_Module NameRegister a dictionary using the current module interpreter.
Add_Data_Source NameAdd a source using the current script.

Globals and expressions

Modules publish named, typed globals such as Audio.Volume; see their references. Appeal maintains the shared registry but does not seed its own fixed script globals. Variables created by Set_Var are separate.

Parenthesized commands supply results to surrounding commands:

Set_Var Score (Add 2 3)
Print Var Score
